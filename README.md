# COMO UTILIZAR O GITHUB

O GitHub é uma plataforma utilizada por desenvolvedores para armazenar, compartilhar e organizar projetos de programação.

## 1. Como Criar uma Conta

- Acesse o site: https://github.com
- Clique em **SIGN UP**.
- Informe seu e-mail.
- Crie uma senha.
- Finalize o cadastro.

## 2. Criando um Repositório

O repositório é o espaço onde seus arquivos e códigos ficam armazenados.

- Entre na sua conta.
- Clique no botão **New**.
- Digite o nome do projeto.
- Adicione uma descrição.
- Escolha se será público ou privado.
- Clique em **Create Repository**.

## 3. Adicionando Arquivos ao Projeto

- Entre no repositório criado.
- Clique em **Add File**.
- Selecione **Upload Files**.
- Escolha os arquivos do seu computador.
- Aguarde o carregamento.
- Clique em **Commit Changes**.

## 4. O que Significa Commit?

Commit é o registro de uma alteração realizada no projeto.

Exemplos de alterações:

- Adicionar uma página HTML.
- Corrigir um erro no código.
- Alterar o design do site.
- Adicionar uma nova funcionalidade.

## 5. Compartilhando o Projeto

- Abra seu repositório.
- Clique em **Code**.
- Copie o endereço do projeto.
- Compartilhe o link com professores, colegas ou recrutadores.
